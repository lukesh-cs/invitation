ALIZA & GOURAV - RING CEREMONY INVITATION

FILES
  index.html, style.css, script.js
  assets/couple.jpg   <- ADD your couple photo here (portrait, about 600x800 or larger)
  assets/music.mp3    <- ADD your romantic music here (keep under ~5 MB)

RUN LOCALLY (VS Code)
  1. Open this folder in VS Code (File > Open Folder).
  2. Install the "Live Server" extension (Ritwick Dey).
  3. Right-click index.html > "Open with Live Server".

PUBLISH FREE
  Netlify Drop: go to app.netlify.com/drop and drag this whole folder in.
  Or GitHub Pages / Cloudflare Pages: upload the files, enable Pages.
  You get a link like https://your-name.netlify.app

QR CODE
  Use a free generator (QR Code Monkey, goqr.me). Paste your published link,
  download as PNG/SVG, and test by scanning with two phones.
